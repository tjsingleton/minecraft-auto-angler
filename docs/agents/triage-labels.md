# Triage labels

Use the same five canonical roles and label strings in Linear's TJ Singleton team.

| Canonical role | Linear label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer needs to evaluate the issue |
| needs-info | needs-info | Waiting on reporter for more information |
| ready-for-agent | ready-for-agent | Fully specified and ready for agent implementation |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

Reuse active team or workspace labels. Do not duplicate labels by changing capitalization
or adding prefixes. Resolve any label ambiguity before applying it.
